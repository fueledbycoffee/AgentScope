## Supported inputs and main path

- The local application imports JSONL, gzip-compressed JSONL and Parquet through
  a FastAPI API and a built React SPA. An import binds each file to an immutable
  mapping revision, previews deterministically, persists canonical sessions and
  recorded model/tool observations, and retains raw-record provenance. See the
  [API contract](../api/v0.1.md) and [architecture](../architecture/import-pipeline.md).
- The clean-clone path uses the committed, attributed TraceLab JSONL.gz fixture
  and bundled `tracelab-v1` mapping. Its expected workflow and observations are
  in the [README quickstart](../../README.md#quickstart-from-a-clean-clone).
- The mapping assistant can run against a configured OpenAI-compatible endpoint
  or the deterministic offline fake. The model proposes data only; explicit
  validate, save, preview and import gates keep canonicalisation inside the
  deterministic engine. See [assistant configuration](../llm/configuration.md).
- SWE-chat has replayed Parquet mapping evidence for two tables, but its gated
  bytes and three reviewed documents are not installed defaults. See the
  [mapping inventory](../mapping/README.md#swe-chat) and
  [dataset inventory](../datasets/README.md#manifest-inventory).
- The current overview exposes four summary values—sessions, recorded model-call
  observations, recorded tool-call observations and input tokens—with exact
  source and agent filters. See the [metric reference](../metrics/README.md).

## Known limits

- One upload is limited to 25 MiB. One import accepts at most 20 files, 100,000
  records and 100 MiB of non-duplicate input bytes; assistant context is limited
  to 64 KiB after trimming. See [API errors and limits](../api/v0.1.md#errors).
- Summary metrics currently support only `source` and `agent` filters and only
  the four values named above. Input tokens are comparable only inside one
  `token_semantics` tag. Metric aggregates are JSON numbers and do not yet have
  a lossless text companion for values above JavaScript's safe-integer range.
  See [metric definitions](../metrics/README.md).
- SWE-chat coverage is partial. Session token/call aggregates are deliberately
  unmapped; conversations have no provider field and unvalidated token
  semantics. `role == "assistant"` includes thinking rows even though an
  assistant row is not necessarily an API call. Tool use and result rows can
  share an id, and the mapping cannot join them, so call end times and latency
  remain unavailable. See the [reviewed mapping limits](../mapping/README.md#swe-chat)
  and [source audit](../verification/2026-09-08-second-source-two-models.md).
- Hosted free models vary across identical requests and can be rate-limited,
  overloaded or retired without notice. Reasoning models need at least the
  recorded 32,768-token budget and a deadline measured in minutes; every
  proposal still requires human review. See the
  [assistant evidence table](../llm/configuration.md#verification).
- The `sources` table exists in the schema but no repository reads or writes it;
  source strings elsewhere are logical namespaces, not foreign keys. See the
  [ERD notes](../architecture/import-pipeline.md#persisted-entities).
- Authentication, hosted deployment, queues, URL/Hugging Face import, CSV,
  command-line import, Postgres, autonomous mapping execution, universal source
  recognition, cross-dataset identity resolution, bulk reprocessing, cost
  estimates, anomaly detection, natural-language questions, transcript search,
  a node mapping designer and plugins are outside the stated v0.1 scope. See
  [Not in v0.1.0](../planning/2026-09-07-consolidated-plan.md#8-not-in-v010).

## Security and data handling

Uploads and the SQLite database are local files under `backend/data/` by
default. `.env` and `data/` are gitignored; keys, raw uploads and gated dataset
bytes must not be committed. Assistant preparation profiles and redacts data,
shows the exact outbound payload, and sends it only after the user proceeds.
Redaction limits exposure but is not anonymisation. Review the
[assistant data boundary](../llm/configuration.md#what-is-sent-and-what-is-not)
and [dataset provenance rules](../datasets/README.md).

## Upgrade and compatibility notes

Startup applies the checked-in Alembic migrations through revision `0003` to
the configured database. This is a pre-release schema and no downgrade or
cross-version compatibility promise has been published. Back up local
`backend/data/` before testing a release candidate against valued data.
